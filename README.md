# FitzHugh-Nagumo モデル シミュレーション

神経細胞の活動電位を記述するFitzHugh-Nagumo（フィッツフュー・南雲）モデルを数値計算するプログラムです。
オイラー法を用いて微分方程式を解き、結果をテキストファイルに出力します。

## ファイル構成

- `FitzHugh-Nagumo.c`: シミュレーションを行うCプログラム
- `graph.plot`: 数値解を可視化するためのgnuplotスクリプト
- `README.md`: このファイル

## コンパイル方法

以下のコマンドでコンパイルしてください。

```bash
gcc FitzHugh-Nagumo.c -o fhn
```

## 実行方法

プログラムは標準入力から外部刺激電流 $I$ (変数 `i`) を受け取ります。

### 1. シミュレーションの実行

入力値 $I$ を指定して数値計算を実行し、結果をファイル（例: `data.txt`）に保存します。

例: $I = 0.5$ の場合

```bash
echo 0.5 | ./fhn > data.txt
```

または対話的に実行する場合:

```bash
./fhn > data.txt
0.5
(Ctrl+D)
```

この操作により、時刻 $t$、膜電位 $v$、回復変数 $w$ の時系列データが `data.txt` に出力されます。

### 2. グラフの作成

`data.txt` がある状態で、以下のコマンドを実行すると `graph.png` が生成されます。

```bash
gnuplot graph.plot
```

## パラメータ設定

プログラム内では以下のパラメータが定数として定義されています。

- $a = 0.7$
- $b = 0.8$
- $c = 10.0$
- 時間刻み $dt = 10^{-4}$

## 出力フォーマット

各行に以下の形式でデータが出力されます。

```
t v w
```

- $t$: 時刻
- $v$: 膜電位
- $w$: 回復変数
